# Observer Configuration, Gotchas, and Best Practices in Blackboard

## Introduction

The Observers feature within Blackboard is a rarely, if ever, used tool by many admins within the application. If you find yourself in a situation where you need to use this feature it can be very confusing and Blackboard/Anthology lacks basic documentation on how to make this work along with what can brake an already assigned observer from having access.
